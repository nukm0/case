# CASE / LAB

Демо открытия кейсов CS2 с виртуальной валютой. Не связано с Valve.

## Запуск
Откройте index.html в современном браузере. Установка зависимостей и сборка не нужны.

## Возможности
- Рулетка с замедлением и поддержкой уменьшения движения.
- Открытые вероятности выпадения: 60%, 25%, 12%, 3%.
- Начальный баланс 1000 монет, кейс за 100 монет, бесплатное пополнение.
- Инвентарь, продажа за виртуальные монеты, сортировка по цене.
- Сохранение баланса и предметов в localStorage браузера.

## Публикация
В Settings → Pages выберите Deploy from a branch, main, / (root).

## Ограничения
Предметы и цены демонстрационные. Нет платежей, вывода, Steam-авторизации или реального инвентаря. Данные хранятся только в браузере и могут редактироваться пользователем. Проверка в браузере пока не выполнена.
